# Tests

## Build and run

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build -j
cd build/tests && ctest --output-on-failure        # all tests
ctest -E "decode_images|decode_modes|timing_correction"   # fast subset (~10 s)
```

Executables are written to `<repo>/bin/` (the top-level `CMakeLists.txt` sets
the runtime output directory), so they can also be run directly, e.g.
`./bin/test_roundtrip`.

## Registered tests (CTest)

| Test | Program | What it checks | Needs |
| --- | --- | --- | --- |
| `vis_codes` | `test_vis_codes.c` | Built-in table of the 43 modes' VIS bytes: every standard 8-bit code has an even number of ones (bit 7 is the parity bit). Prints each code's LSB-first bits and tones (1100 Hz = 1, 1300 Hz = 0). Does not call the library. The build also checks that `vis_codes.json` is valid JSON (needs `python3`). | – |
| `encode_smoke` | `test_encode_smoke.c` | Encodes Scottie 1 at 48 kHz; the generated length is within 1000 samples of `sstv_encoder_get_total_samples()` and the output is not silent. | – |
| `dsp_reference` | `test_dsp_reference.cpp` | 17 tests of the DSP primitives in `src/dsp_filters.cpp` (resonator coefficients, Butterworth IIR, FIR/Hilbert tap symmetry, LPF/HPF/BPF/notch cuts, stability). See [docs/DSP_CONSOLIDATED_GUIDE.md](../docs/DSP_CONSOLIDATED_GUIDE.md). | – |
| `decoder_basic` | `test_decoder_basic.c` | Decoder lifecycle: create/free, invalid sample rate, feeding silence and a 1200 Hz tone, reset, mode hint, `get_image` before an image exists. | – |
| `vis_decode` | `test_vis_decode.c` | 11 synthetic VIS headers are identified correctly. The synthetic tones sit at the detector centres (1080/1320 Hz) rather than the transmitted 1100/1300 Hz, so this also shows the detectors tolerate a 20 Hz offset. | – |
| `roundtrip` | `test_roundtrip.cpp` | **Main regression test.** (1) Encoder tones are exact (VIS 1100/1300 Hz, sync 1200 Hz, black 1500 Hz). (2) For all 43 modes at 11025 Hz: predicted sample count within ±2, the decoder detects the mode from the header alone (VIS, 16-bit VIS or N-VIS, no hint), decodes every line, and the image MAE against the encoded colour bars is < 25 (B/W modes are compared with luma). (3) A transmission sampled +500 ppm fast (Martin 1, Scottie 1, PD120) still decodes with MAE < 25. | – |
| `decode_images` | `test_decode_images.cpp` | Decodes 12 recorded WAVs in `tests/audio/` (Robot 36/72, Scottie 1/2/DX, Martin 1/2, MR73–MR175) and compares each with its reference JPEG; MAE limit 60. | `tests/audio/` |
| `decode_modes` | `test_decode_modes.cpp` | Decodes the 43 WAVs in `tests/test_modes/` with a mode hint for every file; checks the reported mode, image dimensions and that an image was produced (not image quality). Writes PPMs to `tests/decoded_images/` relative to its working directory. | `tests/test_modes/` (gitignored; create with `generate_all_modes`) |
| `timing_correction` | `test_timing_correction.cpp` | Slant/phase regression on recorded files in `tests/audio/` (P7, MR90, P3, MR73, P5; cases whose WAV is missing are skipped) with per-case MAE thresholds of 80–90. | `tests/audio/` |

### Results (2026-09-18, macOS, Release build)

All 9 registered tests pass.

| Test | Result |
| --- | --- |
| `roundtrip` | 43/43 modes, MAE 1.5–16 at 48 kHz and 2–15 at 11025 Hz |
| `decode_images` | 12/12, MAE 11–29 |
| `decode_modes` | 43/43 |
| `timing_correction` | 3 cases run (MR90 27.1, P3 17.1, MR73 26.2) |
| `dsp_reference` | 17/17 |

## Fixtures

| Path | Contents |
| --- | --- |
| `tests/audio/` | Recorded SSTV WAVs (`alt5_test_panel_*.wav`) and the reference images they were made from (`*.jpg`). |
| `tests/test_modes/` | One WAV per mode, generated by this project's encoder (`./bin/generate_all_modes <dir> [rate]`). Gitignored. Files created before 2026-09-18 came from the old encoder (VIS at 1080/1320 Hz, sync at 1181.7 Hz, no AVT or narrow-mode header). The decoder still reads them, but regenerating them is recommended. |
| `tests/decoded_images/` | PPM output of `test_decode_modes`. |
| `tests/vis_codes.json` | VIS reference data for the 43 modes: 8-bit code or 16-bit word, LSB-first bits, bit tones, N-VIS codes for the narrow modes. Generated from `src/modes.cpp`; not read by any test. |
